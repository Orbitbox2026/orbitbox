# OrbitBox

OrbitBox is a Daytona-style Next.js landing page concept for secure AI-code sandbox infrastructure.

## Live Demo

https://daytona-inspired-site.vercel.app

## What the project explains

OrbitBox presents a product concept for running AI-generated code safely inside isolated, elastic sandboxes. The page explains:

- full composable computers for AI agents
- isolated runtime boundaries
- fast sandbox startup
- filesystem and process execution
- preview URLs and PTY access
- snapshots for persistent agent workflows
- human-in-the-loop inspection before shipping

## Design direction

The site is intentionally close to the public Daytona category and positioning: “Run AI Code” and secure elastic infrastructure for AI-generated code. It remains original by using a custom name, logo, animation system, copy structure, and implementation.

## Animations

- animated OrbitBox logo mark
- floating AGENT / API / PTY runtime nodes
- subtle gradient motion behind the hero
- terminal sheen animation
- workflow pulse indicators
- section reveal animations
- reduced-motion support for accessibility
