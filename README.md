# OrbitBox

A polished Next.js landing page inspired by Daytona's secure AI-code runtime concept.

## Features

- Original OrbitBox logo and brand treatment
- Developer-infrastructure landing page
- Header navigation with X social link
- Secure/elastic sandbox runtime messaging
- Responsive layout
- Next.js App Router

## Live Demo

https://daytona-inspired-site.vercel.app

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```
